English Release Notes

  • External Acronis folder (NEW): Driver and program files are no longer embedded in the exe. They are read from the Acronis\ folder next to the exe — a small launcher and easy updates.
  • Dynamic driver loading (NEW): Instead of hardcoded snapman/fltsrv, it auto-scans and loads every *.sys in Acronis\Drivers\.
  • Automatic Defender Management (NEW): The executable file itself appears completely clean to Windows Defender during static scans. However, upon execution, the low-level driver loading and kernel service injections (fltmc load) required for disk imaging are flagged as suspicious/malicious by Defender's behavioral heuristics, blocking application startup. To bypass this operational block, the launcher temporarily registers itself (using its dynamic exe name) into Defender exclusions during runtime and purges the exclusion upon exit.
  • Live Windows safety (NEW): Aborts if an installed Acronis is detected; it also backs up the driver Class keys and restores them on exit.
  • Hybrid detection: Auto-detects WinPE vs Live Windows; in WinPE it leaves already-loaded drivers untouched.
  • Zero dependencies: Works via direct registry in WinPE without sc.exe / powershell (sc.exe is only an optional fallback on pure WinPE).
  • Internal activation: The license is written unconditionally to all paths and opens as full version (version detection removed).
  • Windows 10 fix (NEW): Fixed the 0x100005 "snapshot manager" error on Live Windows 10. sc.exe is now always called from System32, and if service creation fails the service is written directly to the registry.
  • Debug mode (NEW): Run Acronis_Launcher.exe /debug to write acronis_launcher_log.txt next to the exe (environment info, plus the exit code and output of every command).

Windows Defender Dışlama Notu & Mimari Neden

Bu başlatıcı, canlı Windows 10/11 sistemlerinde açılışta arka planda otomatik olarak Add-MpPreference -ExclusionProcess "$EXEFILE" komutunu çalıştırarak kendisini dışlamaya ekler, uygulama kapandığında ise Remove-MpPreference ile bu dışlamayı sistemden tamamen temizler.

Neden Bu Yöntem Tercih Edildi?

  • Statik Temizlik vs Davranışsal Engelleme: Başlatıcı dosyası taranırken Defender tarafında tamamen temiz görünmektedir. Ancak dosya çalıştırıldığında Acronis'in ihtiyaç duyduğu filtre sürücülerini (fltmc load) ve kernel servislerini dinamik olarak sisteme enjekte ederken Defender'ın sezgisel motoru (ML) bu davranışı şüpheli görüp süreci bloklamaktadır. Bu yöntem, dosya bazlı değil davranışsal engellemeyi aşmak için eklenmiştir.
  • Dinamik ve Bağımsız İsim Desteği: Sabit bir klasör yolu yerine $EXEFILE değişkeni kullanılmıştır. Bu sayede derlenmiş dosyanın adı kullanıcı tarafından ne olarak değiştirilirse değiştirilsin (örn. Acronis_v4.exe, Launcher.exe), uygulama kendi adını dinamik olarak algılar ve sürecini Defender'a tanıtır.
  • Geçici ve Temiz Çalışma Prensibi: Kalıcı kural veya kayıt defteri artığı bırakmamak adına dışlama yalnızca başlatıcı çalıştığı süreçte aktif kalır, çıkışta anında silinir. WinPE ortamlarında ise Defender varsayılan olarak aktif olmadığından bu adım pasif geçer.

Windows Defender Exclusion Note & Architectural Reason

On live Windows 10/11 systems, the launcher automatically executes Add-MpPreference -ExclusionProcess "$EXEFILE" in the background upon launch to add itself to exclusions, and invokes Remove-MpPreference upon exit to clean it up completely.

Why Was This Approach Chosen?

  • Static Cleanliness vs Behavioral Blocking: The launcher binary appears completely clean during static AV scans. However, upon execution, as it dynamically loads required filter drivers (fltmc load) and kernel services, Defender's behavioral heuristic engine flags this activity as suspicious and terminates execution. This method is implemented specifically to resolve runtime behavioral blocks.
  • Dynamic & Independent Naming Support: Instead of a fixed directory path, the $EXEFILE variable is utilized. Regardless of how the compiled executable is renamed by the user (e.g. Acronis_v4.exe, Launcher.exe), the app dynamically detects its own name and registers its process with Defender.
  • Transient & Clean Operation Principle: To prevent leaving permanent rules or registry clutter, the exclusion stays active strictly while the launcher runs and is purged upon exit. In WinPE environments where Defender is absent, this step is automatically bypassed.

TÜRKÇE — ADIMLAR

  1. AcronisTrueImage.msi içinden veya C:\Program Files\Acronis\TrueImageHome\WinPE içinden winpe_resources.dll → WinPE.zip açılarak içindeki Files64 klasörü çıkarılır. MSI dosyası için 3. parti bir ayıklama uygulaması gerekir (7-Zip MSI'yi ayıklayamaz); DLL ve ZIP için 7-Zip kullanılabilir.
  2. Files64 klasörü Acronis olarak yeniden adlandırılır.
  3. Exe bu klasörün yanına konup çalıştırılır.

Başka dosya taşıma/yeniden adlandırma gerekmez.

ENGLISH — STEPS

  1. Open winpe_resources.dll → WinPE.zip and extract the Files64 folder from AcronisTrueImage.msi or from C:\Program Files\Acronis\TrueImageHome\WinPE. The MSI file requires a 3rd-party extraction tool (7-Zip cannot extract MSI); 7-Zip can be used for the DLL and ZIP.
  2. Rename the Files64 folder to Acronis.
  3. Place the exe next to that folder and run it.

No other file moving/renaming is needed.

Ağ Paylaşımı Kimlik Bilgisi (opsiyonel) / Network Share Credentials (optional)

TÜRKÇE

SMB/NAS paylaşımına bağlanmak için Acronis'te kayıtlı kimlik bilgileri, Acronis'in çalıştığı ortamda önceden export edilmeli ve smb_creds.reg adıyla exe'nin yanına konmalıdır. Launcher, varsa bu dosyayı açılışta otomatik içe aktarır.

Export edilecek anahtarlar (<IP> = paylaşım sunucusunun adresi):

ENGLISH

The credentials Acronis has saved for connecting to an SMB/NAS share must be exported beforehand and placed next to the exe as smb_creds.reg. The launcher imports this file automatically at startup if it exists.

Keys to export (<IP> = address of the share server):

HKEY_CURRENT_USER\Software\Acronis\Connections\SMB\<IP>
HKEY_USERS\.DEFAULT\Software\Acronis\Connections\SMB\<IP>

TR: Aşağıdaki batch dosyası (örn. export_smb_creds.cmd) iki anahtarı tek bir smb_creds.reg dosyasında birleştirip kendi bulunduğu klasöre kaydeder. Yönetici olarak çalıştırın; kayıtlı tüm SMB sunucuları export edilir.
EN: The batch file below (e.g. export_smb_creds.cmd) merges both keys into a single smb_creds.reg saved next to the script. Run it as administrator; all saved SMB servers are exported. 

@echo off
set "OUT=%~dp0smb_creds.reg"

reg export "HKCU\Software\Acronis\Connections\SMB" "%TEMP%\smb_hkcu.reg" /y
reg export "HKU\.DEFAULT\Software\Acronis\Connections\SMB" "%TEMP%\smb_hku.reg" /y

powershell -NoProfile -Command "$a=Get-Content '%TEMP%\smb_hkcu.reg' -Encoding Unicode; $b=Get-Content '%TEMP%\smb_hku.reg' -Encoding Unicode | Select-Object -Skip 1; ($a+$b) | Set-Content '%OUT%' -Encoding Unicode"

del "%TEMP%\smb_hkcu.reg" "%TEMP%\smb_hku.reg"
echo Done: %OUT%
pause

TR: smb_creds.reg dosyası şifre bilgisi içerir; başkalarıyla paylaşmayın.  ·  EN: smb_creds.reg contains password data; do not share it.
